s01_agent_loop

“One loop & Bash is all you need” — 一个工具 + 一个循环 = 一个 Agent。
Harness 层: 循环 — 模型与真实世界的第一道连接。

  1. 用户输入 => message[](累计式消息列表)

  2. message[] => 大语言模型 LLM ==判断<是否需要工具>==> stop_reason signal

消息列表的格式是：

  • response.content 实际上是LLM的响应
  • results 实际上是客户端命令行工具的运行结果
  1. stop_reason == “toll_use” ? run_bash(command){message.append(tool_result); continue loop} : return result

一个 while True 循环：模型调用工具 -> 执行 -> feedback 反馈 -> loop

从 Claude Code 的实现来看

Claude Code 的核心循环即对上述 Agent Loop 的扩展，以保证结果的稳定性

对于循环结构，CC不使用stop_reson作为标志位，而是直接检查LLM响应体中的tool_use块，
根据tool_use块是否存在决定Agent Loop是否继续，
CC响应体中的状态对象更多

CC存在多条退出路径，覆盖多种实际场景，对于每个场景都有自己的恢复或退出策略

由于大模型的响应是基于字节流的，是流式响应，根据流式输出，可以配置为与流并行的工具调用
