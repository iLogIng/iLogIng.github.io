如何使用 AABB 加速光线追踪

  • Uniform grids 均匀格
  • Spatial partitions 空间划分

Uniform Spatial Partitions (Grids) 统一空间划分（网格）

做光线对盒子的求交，根据格子中的对象状态进行射线求交运算
需要设定合适的网格数

  1. 找到包围盒
  2. 创建网格
  3. 将每个对象存储在重叠的单元格中
  4. 按光线遍历顺序逐步遍历网络
    • 对每个相交的单元格检测存储在其中的对象

若场景中物体分布不均匀，则不适合使用统一的均匀网格进行描述

Spatial Partitions 空间划分

对于稀疏部分，没有使用过多的网格的必要

  • Oct-Tree 八叉树
    • 2D中一般是四叉树
    • nD中是叉树
  • KD-Tree KD树
    • 每次，总是沿一个轴进行切分，划分为类似于二叉树的结构
      • 交替进行水平/竖直划分，以均匀分布
      • nD情况下对个维度进行顺序循环切分
  • BSP-Tree BSP树

以上数据结构，都可以应用于2D或3D实例

KD-Tree

对于KD树，需要求解模型三角形是否与KD-Tree的物理结构有交集，算法难写
一个物体可能出现在多个叶子节点中，KD-Tree并不直观

只需要将模型对象存储在 叶子节点上

  • 内部节点
    • 按轴，进行顺序切分
    • 切分位置垂直于选定轴线
      • 切分位置需要定义
    • 子节点指针
    • 内部节点不保存模型对象
  • 叶子节点
    • 叶子节点保存对象列表

Object Partitions & Bounding Volume Hierarchy (BVH)

物体划分
包围层次体结构
（目前常用）

一个物体只可能出现在一个包围盒中，避免了一个几何结构会出现在多个包围盒中
生成的包围盒可能相交，但相交部分需要尽量少

如何划分节点

  • 选择一个维度进行划分
  • 总是选择剩下的最长轴进行划分
  • 从中位对象进行节点划分（按三角形数量进行划分）

快速选择算法

内部节点

  • 包围盒
  • 子节点指针
    叶子节点
  • 包围盒
  • 对象列表
    节点表示场景中图元的子集
  • 所有的对象都在子树中

Basic radiometry 辐射度量学

在物理上对光照进行准确定义的方法

定义了包含以下关于光照的若干属性：

  • Radiant flux 辐射通量
  • intensity 光强
  • irradiance 辐照度
  • radiance 辐射

Radiance 辐射率（亮度）是表面每单位立体角、每单位投影面积发射、反射、传输或接收的功率

辐射率是描述环境中光分布的基本场量

  • 辐射率是与射线相关的量
  • 渲染就是计算辐射率 Radiance
物理量 概念
Radiance 辐射率 每单位立体角每单位投影的能量

Intensity 光照强度 每单位立体角的能量
Radiance 每单位立体角的Irradiance
Radiance 每单位投影的Intensity

Irradiance: 微分面积 所接收到的所有能量
Radiance: 微分面积从方向 接收到的能量
