Neural Network with loss and gridient

发表于 2026-10-17 更新于 2026-11-15 分类于 机器学习 阅读次数：

一些关于神经网络的理解

一些基于深度学习前馈网络的理解

目标函数（Objective Function） 是在整个训练过程中真正想要最小化（或最大化）的终极目标。
损失函数（Loss Function） 是衡量预测错误的基础度量。
目标函数 = 损失函数 + 正则化项。
工程实践上通常混合使用

残差连接 和 LayerNorm、Multi-Head Attention

在深度神经网络中

  • 神经网络形状
    • 输入矩阵是 特征 是 数据的张量表示
    • 输出是 模型对标签的 预测值
    • 计算的损失函数(loss)是针对网络最后的输出，网络中各个神经元根据该loss通过链式法则进行梯度下降（总趋势是向loss最小的方向下降，所以每个神经元的方向可能不同）
    • 每个神经元都是数据的一种表示 x
    • 神经网络中的各个边代表的是 权重(weight) w
    • 神经网络中，每个神经元的 偏置(bias) b 对该神经元产生的所有加权特征进行平移，以提供更精确的拟合
    • 神经网络中，每个神经元的输出 a 都是标量
    • 每层的 wx + b = y 得到的都是该层神经元的线性输出 z=y ，通过激活函数得到该层的输出，即下一层的 x=a=activation(z)（激活后的z）
  • 激活函数 是在神经元输出前将线性输入非线性化的一种方式
    • 激活函数就是将神经元内部线性变换得到的线性输出（wx + b = y = z）通过非线性变换激活为神经元输出的一种函数，得到下一层的 x

  • 每次反向传播计算梯度前，都需要进行前向传播（计算图），计算当前损失值

    • 在前向传播的过程中，会保存中间产生的每层的输出值(activation(wx… + b))，
    • 反向传播时，从输出层向输入层按链式法则传播
    • 每层神经元根据求导，层层向外求导，activation’ -> (wx… + b)’，同时计算梯度，但不修改权重
      • 梯度 是一个 向量 ，其分量是对 每个参数的 偏导数 用于分别更新各个参数
    • 每个神经元的梯度计算完成后，通过 优化器(一般选择SGD) 根据选定的 学习率 与 求导中产生的梯度 相乘 控制下降步长 进行统一的权重/偏置更新
      • （优化器实际上是通过DataLoader 无干扰选择的部分样本进行前向传播 并更新梯度，以优化反向传播的计算速度的）
        • 网络权重的权重更新仍然的全量的，只不过进行梯度下降更新权重所参考的样本量更精简
        • 得到的梯度值是全样本梯度的一个近似，是无偏估计的应用
      • （学习率，控制了梯度的下降步长）
    • 每层神经元的梯度下降的更新过程是并发的
      • 统一求导，统一更新

  • 损失函数不是网络的一部分 ，而是 网络训练的一部分

    • 构成神经网络输出的就是内部的线性变换与激活函数
    • 损失函数是训练时网络预测与真实参数的度量，是与网络计算分离的
      • 我们的目的是希望损失函数最小，所以在反向传播求导更新参数时需要以损失函数作为起点
      • 损失函数只需要传入两个参数 ，这也是为什么反向传播时会深入网络内部进行参数修改
        • 因为 是通过网络得到的预测量
        • 损失函数 loss 复合了代表了神经网络的函数

  • 正则化

    • 是一种在训练过程中削减/控制过拟合的方法，核心是限制模型复杂度，使隐藏层中的神经元学习不同特征间的隐含联系，防止死记硬背训练数据的噪声。
    • 权重衰减 其中，基于参数的 Ln正则化（L1/L2） 在工程上常被称为 权重衰减(Weight Decay) 。
      • 作用机制：它不影响神经网络的前向传播（计算图不变），而是作用于反向传播的参数更新阶段。
        通过在梯度中增加一个正比于当前权重值的惩罚项（如 L2 的 ），在每次更新时把权重向 0 的方向拉拽。
        • 当权重无限趋近于 0 时，输入的特征参数 x 对应失效（在此处体现了模型的简单性趋向）
        • 降低了模型所依赖的 有效特征维度
      • 效果：这迫使模型的权重无法变得过大，从而让模型函数变得更平滑（降低了对特定训练样本的敏感度），最终提升了模型的泛化能力。
      • 注：这与“减小学习率（降低梯度下降速度）”是两种不同的策略。
        权重衰减的含义，实际上是，通过在梯度更新时增加一个惩罚性质的补偿，将权重向 0 的方向拉拽，保证对于某一个样本的突出特征在更新时不会特别明显而导致针对于该特征的过拟合
        同时也防止两个特征通过巨大的正负权重相互抵消（是在训练时的一种保守的权重更新策略）
    • 暂退法
      • 作用机制：通过影响前向传播时各个节点的层间参数传递
        • 用于 特征 之间， 减少特征的参与量
        • 通常使用
          的方式 随机断开神经元的层间连接 ，制造 随机的特征缺失 ，为保证神经网络在这种随机打断条件下的预测准确性，
          网络被迫让多个神经元共同承担特征表示，各个神经元节点都被迫学习到其他特征的性质，使最终的神经网络模型有更好的 泛化性 。
      • 效果：这迫使网络为保证在 随机打断条件下 网络预测的准确性，让其中各个神经元节点 被迫 学习到其他特征的性质，
        使得最终训练的神经网络模型能够具有更好的 泛化性 。
        • 这实际上是通过让多个神经元节点承担更多的特征预测能力，使每个神经元学习到的是 隐含在不同特征间的联系
      • 与线性代数间可能的联系：
        • 可能与 表示学习(Representation Learning) 这一层面有关
        • 通过随机断连，加强某些特征间的线性组合(神经元网络所选定的输入特征的基变换)，使神经元网络中的各节点更好的利用这种 隐含的额外特征 表示
          • 我理解为 身高 体重 这两个显式的输入特征，通过变换，得到特征间隐含的 食量 这一特征维度（在现有维度中的一个空间）
            • 目前深度学习中所说的 隐层特征(Latent Feature)
            • 与 特征解耦(Feature Disentanglement) 可能有关
            • 降低 特征共适应(Feature Co-adaptation) 对模型鲁棒性的影响
          • 就是让网络发现 未观测到的潜在变量 强迫网络在降维/残缺的 子空间 中 重建 原来的信息
    • 共享参数 (共享层)
      • 作用机制：让多层由一个参数矩阵控制，并在反向传播中累积各共享层的梯度，在梯度下降时使用累积的梯度对各层同时进行更新
        • 用于各层之上， 减少 独立参数 的数量
      • 效果：累积的梯度中，增减可能相互牵制，最后的梯度值可能很小，这迫使 不同层 之间、多条共享的计算路径之间，有更加普适的特征表示
        共享层强迫学习的是 空间/时间上的平移不变性（通用模式） ，强迫学习参数的规律，以逼近现实情况
        以提升模型的 泛化能力
      • 会存在梯度累加无限变大的情况（方向相同）
        • 其实在数学期望上，由于不同路径的方向往往是不同的，所以每次梯度累加时往往会 相互抵消 一部分，而非永远的成倍增加
        • 为防止这个问题，有以下方式：
          • 激活函数与归一化 将梯度的累加拉回一个可控的范围之内（均值为0,方差为1的分布上）
          • 优化器的自适应缩放(Adam) 如 Adam 在更新参数时，不直接使用梯度的原始值。它维护了梯度的“历史移动平均”和“历史平方平均”。自动压缩了步长
          • 梯度裁剪(gradient clipping) 不管梯度累加后有多大，只要超过一个设定的阈值（比如 1.0），就按比例把梯度等比缩放下去

  • 训练数据的 批量规范化 （是一种 跨样本统计 ，需要一个合适的 batch size ）

    • 原因：当网络嵌套层数更深后，深度学习网络拟合为 高复杂度的高阶复合函数 训练时 更难收敛 更容易发生 梯度消失
      在深层网络中，前面层的参数一更新，后面层的输入分布就跟着变，导致后面层得不断地去适应这种变化，使训练极慢甚至梯度消失/爆炸。
      而 BN(Batch Norm) 强行将每一层的输入拉回均值 0、方差 1 的分布，让后面的层能稳定地学习。
    • 作用机制：通过对输入的批量特征数据，对各批进行标准化处理，使其 均值 ， 方差
      将该标准化与优化器配合使用，将参数的量级统一（归化为类似于 高斯分布 的分布特征）
    • 效果：通过小批量规范化
      由于 强行标准化会破坏原本网络学到的特征 ，所以 为了保留网络原本的表达能力 ，所以引入两个 可学习的参数 缩放， 偏移，来重新拟合原分布

  • 残差连接

    • 动机：为解决深层网络的 退化问题 和 梯度消失
    • 机制：在原有的路径上，添加一条旁路捷径
      • 通过引入 让网络只需要学习目标输出与输入之间的差异，并在梯度下降时，能够保证恒等映射作为基础传递方式
    • 原理：让梯度在反向传播时多出一个 +1 的通路，从而无需担心深层网络梯度传递时的梯度消失问题，也不引入会导致梯度爆炸的变量，同时让深层网络更容易学习 恒等映射

  • 最终，神经网络得到的是一个 高度复杂的复合非线性函数

    • 因为神经网络中神经元每层的参数传递，都是一次函数嵌套/复合
