learn-claude-code 笔记

项目路径：github.com/learn-claude-code

README.md

Agent = LLM + Context + Tools

Agent 产品 = 模型 + Harness

LLM: 已训练的神经网络参数模型函数
Agent: 一个通过训练学会了行动的模型，加上让它能在特定环境中工作的基础设施
Agency: 感知、推理、行动

Agent不是过程式的流水线工程，Agency能力是通过模型训练产生的

Harness 是 agent 在特定领域工作所需要的一切：

Harness = Tools + Knowledge + Observation + Action Interfaces + Permissions

  • 工具 Tools: 文件读写、Shell、网络、数据库、浏览器
  • 知识 Knowledge: 产品文档、领域资料、API 规范、风格指南
  • 检测 Observation: git diff、错误日志、浏览器状态、传感器数据
  • 行为 Action: CLI 命令、API 调用、UI 交互
  • 许可 Permissions: 沙箱隔离、审批流程、信任边界

模型决策，harness执行
模型推理，harness提供上下文
此即: Harness => 驾驭工程 | 模型驾驶harness执行任务

Harness 工程

  • 实现工具 Agent的双手
    • 文件读写、Shell、API调用、浏览器控制、数据库查询、…
    • 每个都是Agent在环境中可采取的一个行动
    • 原子化、可组合、描述清晰
  • 策划知识 Agent的领域专长
    • 产品文档、架构决策记录、风格指南、合规要求、…
    • 按需加载(s07)，Agent应知道有什么可用，自己拉取所需
  • 管理上下文 Agent的干净记忆
    • 子Agent隔离(s06)，防止噪声泄漏
    • 上下文压缩(s08)，防止历史淹没
    • 任务系统(s12)，目标持久化到单词对话之外
  • 控制权限 Agent的行为边界
    • 沙箱化文件访问，对破坏性操作要求审批
    • 在Agent和外部系统之间实施信任边界
    • 这是安全工程和harness工程的交汇点
  • 收集任务过程数据 Agent的微调材料
    • Agent在harness中执行的每一条行动序列都是训练信号
    • harness不仅服务于Agent，还可以帮助Agent进化
