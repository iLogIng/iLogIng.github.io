接下来，将以上透视规则投影至屏幕(近平面)上

在图形学中，将*屏幕(screen)抽象为一个二维数组*，每个元素即为屏幕对应位置的像素**，数组的大小即为屏幕的分辨率

  • Raster即为光栅，光栅化即为Rasterization
  • Raster在德语中即表示屏幕，屏幕即为一种光栅化设备
  • Rasterize意为光栅化，即，在屏幕上绘制图像

Pixel意为像素，即Picture element

screen space意为屏幕空间，在屏幕中定义的一个坐标系，比如，取屏幕左上角为原点，向下为Y，向右为X。
可以使用坐标 (x,y) 对各个像素进行访问。
像素索引在 (0,0) ~ (width-1,height-1) 区间内
像素的实际位置(中心)处于 (x+0.5,y+0.5) 处(物理位置)
屏幕对于像素的显示范围为 (0,0) ~ (width,height)

将多边形，拆解为一个个像素，以投射到屏幕，此即光栅化

为什么要以三角形为基础进行光栅化？

  • 三角形为最基础的多边形
    • 其他多边形都可以拆解为三角形
  • 三角形的特性
    • 三个点一定确定一个平面，即，三角形内部一定是一个平面
    • 三角形的内外定义清晰
    • 当给定三角形的三个顶点的属性后，三角形内部平面的各个位置可以进行渐变式的填充（可以进行插值）
    • 可以便捷的判断一个像素与该三角形的空间关系

可以通过采样的方法进行光栅化

采样：给定一个连续函数，在该函数上取离散的各个定点
即，函数的离散化

为了判断某像素是否在三角形内可以使用采样的思维，定义一个函数：

inside(tri,x,y)

  • 1 (x,y) in
  • 0 (x,y) out

关于inside函数，考虑前述课程中向量的叉积

如，对于三角形 p1 p2 p3 另外一个像素 q
然后使用叉积，每次取三个点（px py q，顺序取用三次不同的组合，考虑三角形上的所有顶点的二二组合），使用叉积判断q与向量间的左右关系（叉乘值全为正/负时才能证明q在三角形p1 p2 p3内，边界情况为q在三角形边界）

只需要在三角形所存在的区域（三角形的包围和）内选取各个像素进行判定就可以对三角形进行光栅化（循环处理），而不需要对屏幕空间中的所有点进行判定处理

在光栅化图形学中，由于采样不足而产生像素锯齿，需要抗锯齿技术对产生图形进行处理，以产生较高质量的图形。
