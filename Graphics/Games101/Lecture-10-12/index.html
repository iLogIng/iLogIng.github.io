在图形学中有两种几何：

  • implicit geometry 隐式几何
  • explicit geometry 显式几何

implicit geometry 隐式几何

利用方程进行定义

并不直接指明各个点在什么面上，而是记录各个点相互间满足的几何关系，以此进行面的分类，并不给出实际的点
如：

  • 可以用于表示一个球上的各个顶点

    即，定义一个 表示一个表面的各个点

隐式表示各个点，利于判断点与该区域之间的关系（内/外），但是并不直观

explicit geometry 显式几何

利用集合或参数映射(二维映射为三维)到方式进行定义

如：

对于显式的表面，难以判断点与平面的关系

需要根据需求选择表示方法

在计算机图形学中较多的应用了隐式的表示方法

Constructive Solid Geometry (CSG) (implicit)
通过基本几何的布尔运算定义一个模型

Distance Functions (implicit)
通过描述物体间的距离函数（最小距离）

Fractals (implicit)

Point Cloud 点云

点的列表

理论上可以表示任意种类的几何图形，有利于表示大数据集，通常会变成多边形的面，难以在未经采样区绘制（扫描结果一般为点云）

Polygon Mesh

存储顶点和面（通常是三角形或四边形）

易于处理/采样，适配，使用更加复杂的数据结构

The Wavefront Object File (.obj) Format

是一种文本文件，详细的列出了顶点，法线方向，纹理坐标，以及他们的连接方式

Curves 曲线

Bezier Curves 贝塞尔曲线

使用一系列控制点定义曲线，曲线不一定经过路径上的定义点

de Casteljau Algorithm

考虑三个点下的贝塞尔曲线计算（二次贝塞尔曲线）
三个顶点依次分别为 b0 b1 b2 起点为b0终点为b2

将绘制曲线转化为找一个点的问题
以上的三个顶点产生了两个线段：b0->b1 b1->b2
线段b0->b1上取一点p1使b0->p1=t p1->b1=(1-t)；线段b1->b2上取一点p2使b1->p2=t p2->b2=(1-t)；再在p1->p2上取一点p3使p1->p3=t p3->p2=(1-t)

以上过程产生的p3运动中的路径即为这三个顶点产生的贝塞尔曲线

使用的的方法类似于线性插值，将多个线性插值进行组合
*p1(t) = (1-t)b0 + tb1*
*p3(t) = (1-t)p1 + tp2*
以上式子进行逐层展开

给出n个控制点，可以得到n阶的贝塞尔曲线：
*b^n(t) = b0^n(t) = b0B0^n(t) + … b1*B1^n(t)**
贝塞尔曲线由多个控制点线性组合而成
Bi^n(t) = C(n,i)t^i(1-t)^(n-i) 二次多项式

b(0) = b0 , b(n) = bn

贝塞尔曲线在仿射变换下有一个良好的性质：可以直接对不同的顶点进行仿射变换，可以对变换后的顶点做贝塞尔曲线，得到的曲线与进行仿射变换前的顶点先做贝塞尔曲线再进行仿射变换的结果一致，不需要记录曲线上的每个点，但是对于投影则无该性质

贝塞尔曲线具有凸包性质，即，贝塞尔曲线在定义点形成的凸包内（最小凸多边形内）

Piecewise Bezier Curves

逐段的贝塞尔曲线

习惯于使用四个控制点定义一个贝塞尔曲线（三次贝塞尔曲线）

此时，上一段的第三个控制点、终点与下一段的第二个控制点，这三个控制点共线且产生的两个线段等长时产生一个光滑的连接，即，两端曲线的组合具有连续性

连续：上一段终点为下一段起点
连续： 连续的基础上，两端线段在连接点处的导数相同

Surface 曲面

Bezier Surface 贝塞尔曲面

类似于在纹理中应用的双线性插值

一般由4 * 4即16个控制点进行表示，控制扫描线与扫描线的路径

几何处理/操作

  • Mesh subdivision 网格细分
  • Mesh simplification 网格采样
  • Mesh regularization 网格正规化/标准化

Subdivision 细分

  • 首先，引入更多的三角形
  • 再调整三角形的位置（使模型更加光滑）

Loop Subdivision Loop细分

并不是循环细分，并且仅用于三角形面

将各个三角形根据其各边中点，将其分为四个较小的三角形
此时顶点分为两类，顶点、边上插入点

先产生新顶点，更新新顶点的坐标，再根据周围旧顶点的坐标更新坐标

Catmull-Clark Subdivision

适用于一般情况

将边分为两种：quad face与non-quad face；将度不等于4的点称为奇异点

在处理时，取每一个边与面的中点，且连接边上中点与面上中点
会引入更多的奇异点（原有的奇异点不改变，新奇异点为非四边形面中点），这也仅限于第一次Catmull-Clark，在这之后，原有模型中将不存在非四边形面，不再新增奇异点

根据一系列加权规则进行平均将模型平滑化
