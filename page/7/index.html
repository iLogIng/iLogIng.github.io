三角形的光栅化

在上一节课中讨论到了透视投影，可以将近平面作为显示器（显示平面），定义宽 width和高 height。

即，定义了一个视场 field-of-view(fovY)与宽高比 aspect ratio (width / height) (包括可视角度，在此处，表示为相机到上下边界的开口大小，即视场）

以上两个值直接定义了视锥

令：

视角为fovY

令摄像机到近平面的距离为 |n|

近平面上边界坐标为 (0,t,n)

有：

tan(fovY / 2) = t / |n|

aspect = r / t [width / height ; r=width/2 , t=height/2]

MVP

  • Model Transformation (placing objects)
  • View Transformation (placing camera)
  • Projection Transformation
    • 正交投影 ([-1,1]^3规范立方体)
    • 透视投影

接下来，将以上透视规则投影至屏幕(近平面)上

在图形学中，将*屏幕(screen)抽象为一个二维数组*，每个元素即为屏幕对应位置的像素**，数组的大小即为屏幕的分辨率

  • Raster即为光栅，光栅化即为Rasterization
  • Raster在德语中即表示屏幕，屏幕即为一种光栅化设备
  • Rasterize意为光栅化，即，在屏幕上绘制图像

Pixel意为像素，即Picture element

screen space意为屏幕空间，在屏幕中定义的一个坐标系，比如，取屏幕左上角为原点，向下为Y，向右为X。
可以使用坐标 (x,y) 对各个像素进行访问。
像素索引在 (0,0) ~ (width-1,height-1) 区间内
像素的实际位置(中心)处于 (x+0.5,y+0.5) 处(物理位置)
屏幕对于像素的显示范围为 (0,0) ~ (width,height)

从规范立方体到屏幕

  • 与Z无关
  • 转换至XY平面中： [-1,1]^2 到 [0,width] [0,height]
  • 视口变换矩阵 Viewport transform matrix (屏幕；近面)
    • 将[-1,1]^2变换为屏幕空间

Mviewport
width/2 0 0 width/2
0 height/2 0 heigth/2
0 0 1 0
0 0 0 1

X Y 为标准立方体空间下的坐标 [-1,1] ;
X’ Y’ 为屏幕空间坐标

  • X’ = Xwidth/2 + width/2*
  • Y’ = Yheigth/2 + height/2*

    深度值保留，以便于后续处理

将多边形，拆解为一个个像素，以投射到屏幕，此即光栅化

为什么要以三角形为基础进行光栅化？

  • 三角形为最基础的多边形
    • 其他多边形都可以拆解为三角形
  • 三角形的特性
    • 三个点一定确定一个平面，即，三角形内部一定是一个平面
    • 三角形的内外定义清晰
    • 当给定三角形的三个顶点的属性后，三角形内部平面的各个位置可以进行渐变式的填充（可以进行插值）
    • 可以便捷的判断一个像素与该三角形的空间关系

可以通过采样的方法进行光栅化

采样：给定一个连续函数，在该函数上取离散的各个定点
即，函数的离散化

为了判断某像素是否在三角形内可以使用采样的思维，定义一个函数：

inside(tri,x,y)

  • 1 (x,y) in
  • 0 (x,y) out

关于inside函数，考虑前述课程中向量的叉积

如，对于三角形 p1 p2 p3 另外一个像素 q
然后使用叉积，每次取三个点（px py q，顺序取用三次不同的组合，考虑三角形上的所有顶点的二二组合），使用叉积判断q与向量间的左右关系（叉乘值全为正/负时才能证明q在三角形p1 p2 p3内，边界情况为q在三角形边界）

只需要在三角形所存在的区域（三角形的包围和）内选取各个像素进行判定就可以对三角形进行光栅化（循环处理），而不需要对屏幕空间中的所有点进行判定处理

在光栅化图形学中，由于采样不足而产生像素锯齿，需要抗锯齿技术对产生图形进行处理，以产生较高质量的图形。

反走样 Antialiasing

采样理论 Sampling theory

采样在图形学中无处不在

Sampling Artifacts(Errors/Mistakes/inaccuracies) in Computer Graphics

图形产生走样的原因在于信号(函数)的变化太快(频率很高)，而采样的变化太慢了

进行反走样处理的一种思想：在采样前进行模糊（过滤/滤波）
类似于，先将原图片模糊化，再进行采样
一定是先滤波再采样

频域 Frequency Domain

通过调整cosX sinX两函数中X的系数，可以调整相应的周期函数的频率

详见傅里叶级数展开，傅里叶变换

在采样时，采样频率与信号频率的频率差越大，信息失真越严重
走样，即两个不同频率的信号在采样后，产生的结果无法区分，产生走样

滤波 filter

滤波，即是在采样后除去某些频率成分

傅里叶变换可以将一个函数从实域变换到频域

高通滤波：滤波后只让高频信号通过
可以提取图像内的物体边界，即物体的边界突变

低通滤波：滤波后只让低频信号通过
可以将图像模糊化，即去除了物体边界突变

Filtering = Convolution = Averaging
滤波 = 卷积 = 品均

实域上对两个信号进行卷积，是两个信号频域的乘积

采样，实际上是重复频域上的内容

降低走样

  1. 提高采样率
  2. 反走样
    • 先模糊，后采样（先低通滤波，再采样）
    • 使用一个过滤器对图像进行卷积操作模糊化图像信息(知识近似了图像的覆盖区域)

MSAA(Multi Sample Antialiasing)

  1. 模糊
  2. 采样

还有另外两种抗锯齿方案：

***FXAA(Fast Approximate AA)
***TAA(Temporal AA)

可见性/遮挡 Visibility/occulusion

画家算法
由远及近进行图形的覆盖

深度缓冲 Z-Buffer

  • 记录当前每个样本最小的深度值
  • 对于深度信息，需要一个额外的缓存空间
    • 帧缓冲存储颜色值
    • 深度缓冲(Z-Buffer)存储深度

深度缓冲中各元素初始化值为最远值
维护逐个像素当前能看到的最浅深度
Z-Buffer无法处理透明物体的深度

Shadow

阴影

Shadow Mapping 阴影映射

本质上是一种图像空间的算法，在生成阴影时不需要知道场景的几何信息, 会产生走样现象

当某个顶点不在阴影里，则它在光与摄像机下

经典的Shadow Mapping仅能处理点光源, 产生的是一种硬阴影

  1. 先从光源看向场景，得到深度图
  2. 再从摄像机看向场景，将看到的顶点投影回光源深度图，若深度更深，则此处的光线被遮挡
