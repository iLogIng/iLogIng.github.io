Games101 光栅化

发表于 2025-01-28 更新于 2026-08-07

Rasterization

着色

光栅化 Raster Images

三角形的光栅化

在上一节课中讨论到了透视投影，可以将近平面作为显示器（显示平面），定义宽 width和高 height。

即，定义了一个视场 field-of-view(fovY)与宽高比 aspect ratio (width / height) (包括可视角度，在此处，表示为相机到上下边界的开口大小，即视场）

以上两个值直接定义了视锥

令：

视角为fovY

令摄像机到近平面的距离为 |n|

近平面上边界坐标为 (0,t,n)

有：

tan(fovY / 2) = t / |n|

aspect = r / t [width / height ; r=width/2 , t=height/2]

MVP

  • Model Transformation (placing objects)
  • View Transformation (placing camera)
  • Projection Transformation
    • 正交投影 ([-1,1]^3规范立方体)
    • 透视投影

接下来，将以上透视规则投影至屏幕(近平面)上

在图形学中，将*屏幕(screen)抽象为一个二维数组*，每个元素即为屏幕对应位置的像素**，数组的大小即为屏幕的分辨率

  • Raster即为光栅，光栅化即为Rasterization
  • Raster在德语中即表示屏幕，屏幕即为一种光栅化设备
  • Rasterize意为光栅化，即，在屏幕上绘制图像

Pixel意为像素，即Picture element

screen space意为屏幕空间，在屏幕中定义的一个坐标系，比如，取屏幕左上角为原点，向下为Y，向右为X。
可以使用坐标 (x,y) 对各个像素进行访问。
像素索引在 (0,0) ~ (width-1,height-1) 区间内
像素的实际位置(中心)处于 (x+0.5,y+0.5) 处(物理位置)
屏幕对于像素的显示范围为 (0,0) ~ (width,height)

从规范立方体到屏幕

  • 与Z无关
  • 转换至XY平面中： [-1,1]^2 到 [0,width] [0,height]
  • 视口变换矩阵 Viewport transform matrix (屏幕；近面)
    • 将[-1,1]^2变换为屏幕空间

Mviewport
width/2 0 0 width/2
0 height/2 0 heigth/2
0 0 1 0
0 0 0 1

X Y 为标准立方体空间下的坐标 [-1,1] ;
X’ Y’ 为屏幕空间坐标

  • X’ = Xwidth/2 + width/2*
  • Y’ = Yheigth/2 + height/2*

    深度值保留，以便于后续处理

将多边形，拆解为一个个像素，以投射到屏幕，此即光栅化

为什么要以三角形为基础进行光栅化？

  • 三角形为最基础的多边形
    • 其他多边形都可以拆解为三角形
  • 三角形的特性
    • 三个点一定确定一个平面，即，三角形内部一定是一个平面
    • 三角形的内外定义清晰
    • 当给定三角形的三个顶点的属性后，三角形内部平面的各个位置可以进行渐变式的填充（可以进行插值）
    • 可以便捷的判断一个像素与该三角形的空间关系

可以通过采样的方法进行光栅化

采样：给定一个连续函数，在该函数上取离散的各个定点
即，函数的离散化

为了判断某像素是否在三角形内可以使用采样的思维，定义一个函数：

inside(tri,x,y)

  • 1 (x,y) in
  • 0 (x,y) out

关于inside函数，考虑前述课程中向量的叉积

如，对于三角形 p1 p2 p3 另外一个像素 q
然后使用叉积，每次取三个点（px py q，顺序取用三次不同的组合，考虑三角形上的所有顶点的二二组合），使用叉积判断q与向量间的左右关系（叉乘值全为正/负时才能证明q在三角形p1 p2 p3内，边界情况为q在三角形边界）

只需要在三角形所存在的区域（三角形的包围和）内选取各个像素进行判定就可以对三角形进行光栅化（循环处理），而不需要对屏幕空间中的所有点进行判定处理

在光栅化图形学中，由于采样不足而产生像素锯齿，需要抗锯齿技术对产生图形进行处理，以产生较高质量的图形。

Games101 反走样与深度缓冲

发表于 2025-01-28 更新于 2026-08-07

Rasterization

着色

图像保真与深度缓冲
Antialiasing and Z-Buffering

反走样 Antialiasing

采样理论 Sampling theory

采样在图形学中无处不在

Sampling Artifacts(Errors/Mistakes/inaccuracies) in Computer Graphics

图形产生走样的原因在于信号(函数)的变化太快(频率很高)，而采样的变化太慢了

进行反走样处理的一种思想：在采样前进行模糊（过滤/滤波）
类似于，先将原图片模糊化，再进行采样
一定是先滤波再采样

频域 Frequency Domain

通过调整cosX sinX两函数中X的系数，可以调整相应的周期函数的频率

详见傅里叶级数展开，傅里叶变换

在采样时，采样频率与信号频率的频率差越大，信息失真越严重
走样，即两个不同频率的信号在采样后，产生的结果无法区分，产生走样

滤波 filter

滤波，即是在采样后除去某些频率成分

傅里叶变换可以将一个函数从实域变换到频域

高通滤波：滤波后只让高频信号通过
可以提取图像内的物体边界，即物体的边界突变

低通滤波：滤波后只让低频信号通过
可以将图像模糊化，即去除了物体边界突变

Filtering = Convolution = Averaging
滤波 = 卷积 = 品均

实域上对两个信号进行卷积，是两个信号频域的乘积

采样，实际上是重复频域上的内容

降低走样

  1. 提高采样率
  2. 反走样
    • 先模糊，后采样（先低通滤波，再采样）
    • 使用一个过滤器对图像进行卷积操作模糊化图像信息(知识近似了图像的覆盖区域)

MSAA(Multi Sample Antialiasing)

  1. 模糊
  2. 采样

还有另外两种抗锯齿方案：

***FXAA(Fast Approximate AA)
***TAA(Temporal AA)

可见性/遮挡 Visibility/occulusion

画家算法
由远及近进行图形的覆盖

深度缓冲 Z-Buffer

  • 记录当前每个样本最小的深度值
  • 对于深度信息，需要一个额外的缓存空间
    • 帧缓冲存储颜色值
    • 深度缓冲(Z-Buffer)存储深度

深度缓冲中各元素初始化值为最远值
维护逐个像素当前能看到的最浅深度
Z-Buffer无法处理透明物体的深度

Geometry

几何

Introduction to Geometry

  • 曲线/面
  • 复杂单体
  • 液体
  • 布料
  • 复杂组合
  • 毛发
  • 微观物体

在图形学中有两种几何：

  • implicit geometry 隐式几何
  • explicit geometry 显式几何

implicit geometry 隐式几何

利用方程进行定义

并不直接指明各个点在什么面上，而是记录各个点相互间满足的几何关系，以此进行面的分类，并不给出实际的点
如：

  • f(x,y,z) = x^2 + y^2 + z^2 = 1 可以用于表示一个球上的各个顶点

    即，定义一个f(x,y,z) = 0表示一个表面的各个点

隐式表示各个点，利于判断点与该区域之间的关系（内/外），但是并不直观

explicit geometry 显式几何

利用集合或参数映射(二维映射为三维)到方式进行定义

f(u,v) = (x,y,z)

如：

f(u,v) = ((2 + cosu)cosv, (2 + cosv)sinv, sinu0)

对于显式的表面，难以判断点与平面的关系

需要根据需求选择表示方法

在计算机图形学中较多的应用了隐式的表示方法

Constructive Solid Geometry (CSG) (implicit)
通过基本几何的布尔运算定义一个模型

交 并 差

Distance Functions (implicit)
通过描述物体间的距离函数（最小距离）

Fractals (implicit)

分形

应用不多

Point Cloud 点云

点的列表

理论上可以表示任意种类的几何图形，有利于表示大数据集，通常会变成多边形的面，难以在未经采样区绘制（扫描结果一般为点云）

Polygon Mesh

存储顶点和面（通常是三角形或四边形）

易于处理/采样，适配，使用更加复杂的数据结构

The Wavefront Object File (.obj) Format

是一种文本文件，详细的列出了顶点，法线方向，纹理坐标，以及他们的连接方式

.obj格式文件介绍

Curves 曲线

Bezier Curves 贝塞尔曲线

使用一系列控制点定义曲线，曲线不一定经过路径上的定义点

de Casteljau Algorithm

考虑三个点下的贝塞尔曲线计算（二次贝塞尔曲线）
三个顶点依次分别为 b0 b1 b2 起点为b0终点为b2

将绘制曲线转化为找一个点的问题
以上的三个顶点产生了两个线段：b0->b1 b1->b2
线段b0->b1上取一点p1使b0->p1=t p1->b1=(1-t)；线段b1->b2上取一点p2使b1->p2=t p2->b2=(1-t)；再在p1->p2上取一点p3使p1->p3=t p3->p2=(1-t)

以上过程产生的p3运动中的路径即为这三个顶点产生的贝塞尔曲线

使用的的方法类似于线性插值，将多个线性插值进行组合
*p1(t) = (1-t)b0 + tb1*
*p3(t) = (1-t)p1 + tp2*
以上式子进行逐层展开

给出n个控制点，可以得到n阶的贝塞尔曲线：
*b^n(t) = b0^n(t) = b0B0^n(t) + … b1*B1^n(t)**
贝塞尔曲线由多个控制点线性组合而成
Bi^n(t) = C(n,i)t^i(1-t)^(n-i) 二次多项式

b(0) = b0 , b(n) = bn

贝塞尔曲线在仿射变换下有一个良好的性质：可以直接对不同的顶点进行仿射变换，可以对变换后的顶点做贝塞尔曲线，得到的曲线与进行仿射变换前的顶点先做贝塞尔曲线再进行仿射变换的结果一致，不需要记录曲线上的每个点，但是对于投影则无该性质

贝塞尔曲线具有凸包性质，即，贝塞尔曲线在定义点形成的凸包内（最小凸多边形内）

Piecewise Bezier Curves

逐段的贝塞尔曲线

习惯于使用四个控制点定义一个贝塞尔曲线（三次贝塞尔曲线）

此时，上一段的第三个控制点、终点与下一段的第二个控制点，这三个控制点共线且产生的两个线段等长时产生一个光滑的连接，即，两端曲线的组合具有连续性

C0连续：上一段终点为下一段起点
C1连续：C0连续的基础上，两端线段在连接点处的导数相同

Surface 曲面

Bezier Surface 贝塞尔曲面

类似于在纹理中应用的双线性插值

一般由4 * 4即16个控制点进行表示，控制扫描线与扫描线的路径

几何处理/操作

  • Mesh subdivision 网格细分
  • Mesh simplification 网格采样
  • Mesh regularization 网格正规化/标准化

Subdivision 细分

  • 首先，引入更多的三角形
  • 再调整三角形的位置（使模型更加光滑）

Loop Subdivision Loop细分

并不是循环细分，并且仅用于三角形面

将各个三角形根据其各边中点，将其分为四个较小的三角形
此时顶点分为两类，顶点、边上插入点

先产生新顶点，更新新顶点的坐标，再根据周围旧顶点的坐标更新坐标

Catmull-Clark Subdivision

适用于一般情况

将边分为两种：quad face与non-quad face；将度不等于4的点称为奇异点

在处理时，取每一个边与面的中点，且连接边上中点与面上中点
会引入更多的奇异点（原有的奇异点不改变，新奇异点为非四边形面中点），这也仅限于第一次Catmull-Clark，在这之后，原有模型中将不存在非四边形面，不再新增奇异点

根据一系列加权规则进行平均将模型平滑化

Simplification 简化

可联系MipMap进行理解

Edge Collapsing 边坍缩

Quadric Error Metrics 二次误差度量

Shadow Mapping 阴影映射

本质上是一种图像空间的算法，在生成阴影时不需要知道场景的几何信息, 会产生走样现象

当某个顶点不在阴影里，则它在光与摄像机下

经典的Shadow Mapping仅能处理点光源, 产生的是一种硬阴影

  1. 先从光源看向场景，得到深度图
  2. 再从摄像机看向场景，将看到的顶点投影回光源深度图，若深度更深，则此处的光线被遮挡
