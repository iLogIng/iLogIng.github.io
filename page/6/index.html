计算机网络概观

发表于 2025-10-17 更新于 2026-08-07

基于 《计算机网络：自顶向下方法》

因特网是一个世界范围内的计算机网络

入网设备 被称为 主机(host) 或 段系统(end system)

端系统通过

  • 通信链路 (communication link)
  • 分组交换机 (packet switch)

的网络连接在一起。

通信链路 是一组物理媒介，是信息流的载体。

链路 有由其性质决定的 传输速率(transmission rate) 以 bit/s (bps) 为度量。

网络中的信息是以信息包的形式被 分组(packet) 流通的，从始端由网络传送至目的端，并在目的端装配复原。

当今，因特网中有两种常见的交换机：

  • 路由器 (router) 通常用于网络核心中
  • 链路层交换机 (link-layer switch) 通常用于接入网中

关于JavaScript特性与异步模型

执行上下文

JS在第一次执行时会根据web引擎创建 全局上下文 在该上下文中运行JS脚本，在 调用函数时 从内存堆中提取函数 创建该函数的函数执行上下文 再将程序的执行转入 该函数上下文中 函数执行后再 返回全局上下文（这与C/C++的函数栈帧不同，反倒与thread机制类似，即进行上下文的保存和转换， 据此可推知： JS所实现的单线程异步是以此为基础实现的）

  • 关于JS中函数的存储

    是的，JS将定义的函数及其形参都按一定规则存入内存堆，在调用时从堆中提取。

调用栈

调用栈是JS引擎 跟踪 被调用函数所处位置的方式，JS使用其管理 执行上下文。

JS为每个被调用的函数创建一个 函数上下文 并依次压入调用栈中，由于JS为单线程语言，所以 只维护一个调用栈 当栈空后 脚本停止 。当执行的是一个递归函数，且陷入无限递归时会产生 栈溢出。

由于JS为单线程语言，只维护一个调用栈，所以 一次只执行一个操作 所有操作都是 同步的 而JS的 异步 特性可以在等待另一个任务完成时，执行其他任务。

事件循环

JS引擎从文件顶部向下执行，创建 执行上下文 和 管理 调用堆栈

在程序运行时，有可能会遇到执行时间很长的 阻塞函数 会阻塞交互行为，

所以使用Web API传入回调函数，函数向宿主环境发送任务消息后返回上一层上下文继续执行，其任务交由宿主环境进行处理，再接收宿主环境返回的完成信息（包含之前所注册的回调函数），压入 任务队列 （或回调队列），再由 事件循环 检查任务队列中的内容，当 调用栈 和 任务队列 都为空后 脚本停止 。

为什么要学习变换？

变换可以分为两类：

  1. 模型变换(Modeling)
    • 旋转 rotation
    • 缩放 scale
    • 切变 shear
  2. 视角变换(Viewing)
    • 3D转换为2D的投影 projection

2D变换

旋转 rotation

在2D变换中，将物体绕原点（或某一个点）进行旋转（默认向逆时针方向进行旋转

实质上是变换向量空间

2D旋转矩阵：

cosO -sinO
sinO cosO

缩放 scale

在2D变换中，向量缩放则是通过左乘一个包含了向各个线性无关方向进行伸缩变换系数的对角矩阵。

由此，也可以对向量进行对称（镜像）

切变 shear

在2D变换中，物体的某一部分相对于另一部分在某一方向发生变化。如，在平面直角坐标系中，正方形变换为菱形。

齐次坐标 Homogeneous Coordinates

在处理平移时无法表示为以上所述的形式，而是：

  • x’ = x + Tx
  • y’ = y + Ty

在包含平移后公式形式变为：

  • x’ = ax + by + Tx

若要将平移与上述三种变换进行统一的变换，于是引入了齐次坐标

可以在2D坐标/点上增加一个维度，变为：

罗德里格斯旋转公式：

R(n,a) 该公式给出了一个旋转矩阵，定义了一个旋转轴n(方向)与旋转角度a

公式推导

罗德里格斯旋转公式

wiki

在公式推导过程中的核心逻辑为：罗德里格斯公式的本质就是将三维旋转分解为平行分量的保留和垂直分量的二维旋转，然后用向量加法重新组合。

对该公式的理解：取一旋转轴n(n为旋转轴方向上的单位向量)，绕该旋转轴有一旋转角a。为辅助公式的推导，令旋转轴n的一个法平面为s。

step1
计算出*v与vrot**在n轴法向平面s上的投影

step2
将法平面上的两个投影围成一个直角三角形，其中vrot的投影作为斜边，可以清晰地以该斜边为半径，在平面s上做出一个圆形。将向量v绕n轴旋转到向量vrot的运动，拆分成两段向量，即上述直角三角形产生的两个直角边。

step3
使用公式，将vrot分解出的两个向量用v分解出的两个向量代替。最后，使用v表示vrot，即得到罗德里格公式。

观测变换 Viewing Transformations

视图/相机变换 View/Camera transformation

  • 模型变换 model transformation 搭建场景
  • 视图变换 view transformation 变换摄像头
  • 投影变换 projection thransformation 将3D投影至2D

    以上变换成为MPV变换(Model View Projection)

定义相机：

  • 位置 Position e
  • 朝向 Look-at/gaze direction g
  • 向上方向 Up direction t

将相机放在标准位置——坐标轴原点——上。y轴为上，z轴负方向朝向物体。

  1. 先将相机移动至原点
    Tview
    1 0 0 -Xe
    0 1 0 -Ye
    0 0 1 -Ze
    0 0 0 1

  2. g 旋转至与***-Z***对齐

  3. t 旋转至与Y对齐

  4. g cross t得到X

对于进行以上的变换，难以求出，可以先求其逆变换，即求将各个坐标轴变换至各个相机方向的变换矩阵。

Rview^(-1)
X(g cross t) Xt X(-g) 0
Y(g cross t) Yt Y(-g) 0
Z(g cross t) Zt Z(-g) 0
0 0 0 1

由于旋转矩阵是正交矩阵，其逆与其转置相等。

Rview OR Rview^T
X(g cross t) Y(g cross t) Z(g cross t) 0
Xt Yt Zt 0
X(-g) Y(-g) Z(-g) 0
0 0 0 1

在进行视图变换的同时，相机与物体应用同样的变换，保证相对位置的不变
即模型/视图变换

投影变换 Projection transformation

正交投影 Orthographic projection

由物体直接竖直投影至画布上

  • 设定相机位置
  • 丢弃Z轴信息
  • 移动并缩放将投影图形限制在一个[-1,1]^2矩形中（人为约定的限制）

在图形学中，我们将一个显示空间：
[l,r] [b,t] [f,n](左右 上下 远近)
变换为一个[-1,1]^3立方体空间

注意，在右手系中，表示远近的[f,n]中由于摄像头朝向-Z方向，越远f越小

Mortho = Mscale * Mtrans

Mtrans
1 0 0 -(r+l)/2
0 1 0 -(t+b)/2
0 0 1 -(n+f)/2
0 0 0 1

摄像机归中

Mscale
2/(r-l) 0 0 0
0 2/(t-b) 0 0
0 0 2/(n-f) 0
0 0 0 1

缩放至[-1,1]区间

透视投影 Perspective projection

（视锥中的）物体通过各顶点与视点（相机原点）的连线投影至画布上（与画布的焦点）

是最常使用的投影，遵循近大远小的视觉原理

  • 将相机与画布间的距离记为n
  • 将相机与物体间的距离记为z
  • 将物体在空间中的位置记为**(x,y,z)**
  • 将物体在画布上的位置记为**(x’,y’,z’)**

(根据相似三角形）对x,y,z有：

  • x’ = (n/z) * x

在齐次坐标系下：

(x,y,z,1) => (nx/z,ny/z,unknown,1) == (nx,ny,unknown,z)

Mpersp->ortho(x,y,z,1) = (nx,ny,unknown,z)
此时，至少可知：
Mpresp->ortho
n 0 0 0
0 n 0 0
? ? ? ?
0 0 1 0

在近平面上任意点不发生变化

使用n来代替z：
(x,y,n,1) => (x,y,n,1) == (nx,ny,n^2,n)
Mpresp->ortho(x,y,n,1) = (nx,ny,n^2,n)

对于Mpresp->ortho的第三行为：
(0,0,A,B)有：

(0,0,A,B) * (x,y,n,1) = n^2

nA + B = n^2

在远平面上任意点的Z坐标不发生变化

取，远平面的中心点
(0,0,f,1) => (0,0,f,1) == (0,0,f^2,f)
Mpresp->ortho(0,0,f,1) = (0,0,f^2,f)

(0,0,A,B) * (0,0,f,1) = f^2

fA + B = f^2

联立上述两式可得出：
A=n+f
B=-nf

Mpersp->ortho
n 0 0 0
0 n 0 0
0 0 n+f -nf
0 0 1 0

Mpersp = Mortho Mpersp->ortho

在近平面n与远平面f之间的点，近的更近 被拉伸
在远平面f之外的（远处）点，远的更远 被压缩
这就是透视畸变 现象
