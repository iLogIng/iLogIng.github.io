寄存器名称与主要用途

寄存器 传统名称 主要用途
RAX 累加器 (Accumulator) 函数返回值、算术运算、系统调用号
RCX 计数器 (Counter) 第4个整数参数、循环计数、通用寄存器
RDX 数据寄存器 (Data) 第3个整数参数、与RAX配合用于乘除法、通用寄存器
RBX 基址寄存器 (Base) 被调用者保存、常用于存储基地址
RSP 栈指针 (Stack Pointer) 指向当前栈顶、永远指向内存中的栈顶
RBP 基址指针 (Base Pointer) 被调用者保存、通常用作栈帧基址（可选）
RSI 源索引 (Source Index) 第2个整数参数、字符串/数组操作源地址
RDI 目的索引 (Destination Index) 第1个整数参数、字符串/数组操作目的地址

Makefile

在Linux环境下，常常使用make程序自动化变异大型源码。
项目提供一个Makefile文件，make以此为基础进行程序的编译和链接。
make并不限定为构建C/C++项目服务，还可以用于任何文件的组织与处理，但主要用于Unix/Linux环境的自动化开发。

Makefile基础

在Linux环境下，输入make命令，程序在当前目录下查找一个名为Makefile的文件，然后，根据该文件定的规则，自动化的执行任意命令。

规则

计算机网络概观

发表于 2025-10-17 更新于 2026-08-08 分类于 计算机网络

基于 《计算机网络：自顶向下方法》

因特网是一个世界范围内的计算机网络

入网设备 被称为 主机(host) 或 段系统(end system)

端系统通过

  • 通信链路 (communication link)
  • 分组交换机 (packet switch)

的网络连接在一起。

通信链路 是一组物理媒介，是信息流的载体。

链路 有由其性质决定的 传输速率(transmission rate) 以 bit/s (bps) 为度量。

网络中的信息是以信息包的形式被 分组(packet) 流通的，从始端由网络传送至目的端，并在目的端装配复原。

当今，因特网中有两种常见的交换机：

  • 路由器 (router) 通常用于网络核心中
  • 链路层交换机 (link-layer switch) 通常用于接入网中

Asio

Boost.Asio 是一个跨平台的C++库，用于网络和底层I/O编程，它使用现代C++方法为开发人员提供一致的异步模型。

  • 库学习建议

    核心概念优先级：

    1. io_context + 异步操作模型 ✓
    2. TCP/UDP编程基础 ✓
    3. 异步回调与completion handler ✓
    4. 定时器与deadline_timer ✓
    5. 简单的异步链 ✓

    可暂缓的内容：

    • 复杂的proactor模式理论
    • 所有高级特性（如协程支持）
    • 性能优化细节
