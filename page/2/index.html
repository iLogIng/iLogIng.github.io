Docker Note

Docker

容器化： 是一种 轻量级 的操作系统虚拟化方法。将应用、依赖、配置等集成为一个专有环境
具有：

  • 可移植性
    • 在一次构建与配置后，可以在任何装有Docker引擎的环境中一致运行
  • 更轻量化
    • 通过直接共享主机的操作系统内核，达到了相对于完整的虚拟机模拟程序， 更快的启动速度 、 更低的资源占用 的效果
    • 一台物理机可同时运行上千个容器
  • 资源隔离
    • 每个容器都拥有其自己独立的文件系统、网络和进程空间，互不干扰，安全性更高

RISC-V 架构的三种模式（保留了一种）

Level Encode Name Abbreviation
0 00 User/Application 用户模式 U
1 01 Supervisor 监管者模式 S
2 10 Reserved 保留 -
3 11 Machine 机器模式 M

xv6 系统启动流程

阅读内核代码最好从启动入口开始，针对启动时的主要调用进行跟踪式的阅读

在kernel/目录下

  • kernel.ld
    • 控制程序的内存模型
    • 控制 entry.S 的链接位置
    • 控制 _trampoline 在程序中的内存位置

  1. entry.S

    • 为每个hart(硬件线程)分配栈空间
    • call start -> start.c/start()

  2. start.c/start() 启动时钟中断、 main.c/main()

    • w_mepc((uint64)main)
    • asm volatile (mret) -> main.c/main()

  3. main.c/main()
