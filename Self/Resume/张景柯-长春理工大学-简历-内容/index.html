WAV 容器解析与编解码库 WavProcesser | C++17、CMake、GTest | 2026.10 | 独立开发

• 覆盖 U8/S16/S24/S32/F32/F64 六种采样格式的读写与相互转换，支持 WAVE_FORMAT_EXTENSIBLE 扩展头（有效位深 / 通道掩码 / GUID）解析。
• 实现 IMA ADPCM 编解码：块头解析、跨块 predictor 状态延续、奇数字节 pad，并以 PCM 往返比对校验解码正确性。
• 5 个测试模块覆盖容器解析、样本编解码、ADPCM、文件 IO 与往返一致性。

异步 HTTP 服务器 | C++17、Boost(Asio / Beast)、Docker、CMake | 2026.04 - 2026.08 | 独立开发
• 基于 Proactor 模型实现异步 HTTP/1.1 服务器，支持多线程 I/O 复用、连接超时控制与优雅关闭（信号捕获 + 会话排空 + 强制超时）。
• 以 RAII 管理连接生命周期；实现路由分发、静态文件服务与动态 API 端点注册表（method + path 自由注册）。
• 安全与限流：路径穿越双重校验、请求体大小限制（413）、连接限流（503 + Retry-After 头）。
• 实现 gzip 内容协商（Accept-Encoding + Vary，Range 请求不压缩）与线程安全的 LRU 文件缓存；支持配置优先级：命令行 > JSON > 默认值。
• Google Test 单元测试与端到端集成测试共 140 用例；wrk 压测（8 线程 / 400 连接）峰值约 150k QPS，测试环境与数据留档于 docs/stress-test。

内存键值存储 tinyKVCache | C++17、CMake、GTest、epoll | 2026.09 | 独立开发
• 零依赖实现有界 LRU 缓存：槽位池 + 侵入式双向链表，O(1) 复杂度内完成缓存单元的定位与淘汰。
• 实现 AOF 持久化：长度前缀记录格式（支持任意字节值的存储）、三种 fsync 策略（always 立即写盘 / group 批量合并 / os 交由操作系统控制回写），写失败不修改内存以保证日志与内存一致。
• 启动时按写序回放 AOF 重建缓存；末尾不完整记录自动截断恢复。
• 网络层自实现帧编解码 + 事件循环服务端 + 客户端库，支持 pipeline 批量发送接收，兼容 RESP2 子集（能够与redis服务器进行简单交互）。
• 8 个测试模块覆盖 LRU 缓存、分词解析、日志回放、帧编解码与客户端集成。
