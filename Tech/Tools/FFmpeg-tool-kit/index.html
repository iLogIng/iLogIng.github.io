FFmpeg Note

FFmpeg 是 Fabrice Bellard 发起的项目

FFmpeg 提供以下三种工具

  • ffmpeg
    • 处理与转码
    • 核心工具，用于转码、剪辑、合并、滤镜等几乎所有处理任务
  • ffprobe
    • 分析信息
    • 可以快速查看任何媒体文件的容器、流、编码、时长等信息
  • ffplay
    • 播放验证
    • 一个极简的媒体播放器，用于快速验证文件是否能正常解码播放

上述三个工具的命令行都会产生以下文本

head

版本和版权

body

编译器
编译配置 是构建这套 FFmpeg（ffmpeg、ffprobe、ffplay 还有其他套件）时的总配置摘要，其中包含 GCC 的编译/链接参数
内部库版本
其中的库前缀 av: Audio/Video 音视频通用基础 | sw: Software 软件处理实现

tail

ffprobe 简单多媒体流解析器

ffplay 简单媒体播放器

ffmpeg 通用媒体转换器

上述信息可以使用
-hide_banner 关闭上述信息，保留工具都回显信息
-loglevel 控制日志输出级别
可以使用 -v quiet 完全静默回显信息
