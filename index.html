learn-claude-code 笔记

项目路径：github.com/learn-claude-code

README.md

Agent = LLM + Context + Tools

Agent 产品 = 模型 + Harness

LLM: 已训练的神经网络参数模型函数
Agent: 一个通过训练学会了行动的模型，加上让它能在特定环境中工作的基础设施
Agency: 感知、推理、行动

Agent不是过程式的流水线工程，Agency能力是通过模型训练产生的

Harness 是 agent 在特定领域工作所需要的一切：

Harness = Tools + Knowledge + Observation + Action Interfaces + Permissions

  • 工具 Tools: 文件读写、Shell、网络、数据库、浏览器
  • 知识 Knowledge: 产品文档、领域资料、API 规范、风格指南
  • 检测 Observation: git diff、错误日志、浏览器状态、传感器数据
  • 行为 Action: CLI 命令、API 调用、UI 交互
  • 许可 Permissions: 沙箱隔离、审批流程、信任边界

模型决策，harness执行
模型推理，harness提供上下文
此即: Harness => 驾驭工程 | 模型驾驶harness执行任务

s01_agent_loop

“One loop & Bash is all you need” — 一个工具 + 一个循环 = 一个 Agent。
Harness 层: 循环 — 模型与真实世界的第一道连接。

  1. 用户输入 => message[](累计式消息列表)

  2. message[] => 大语言模型 LLM ==判断<是否需要工具>==> stop_reason signal

  3. stop_reason == “toll_use” ? run_bash(command){message.append(tool_result); continue loop} : return result

一个 while True 循环：模型调用工具 -> 执行 -> feedback 反馈 -> loop

Docker Note

Docker

容器化： 是一种 轻量级 的操作系统虚拟化方法。将应用、依赖、配置等集成为一个专有环境
具有：

  • 可移植性
    • 在一次构建与配置后，可以在任何装有Docker引擎的环境中一致运行
  • 更轻量化
    • 通过直接共享主机的操作系统内核，达到了相对于完整的虚拟机模拟程序， 更快的启动速度 、 更低的资源占用 的效果
    • 一台物理机可同时运行上千个容器
  • 资源隔离
    • 每个容器都拥有其自己独立的文件系统、网络和进程空间，互不干扰，安全性更高
